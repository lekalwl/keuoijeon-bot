# 크외전 Discord Bot

크로커 외전(1.5기)용 Discord 봇입니다.

## 명령어

- `/캐릭터 등록 이름 힘 민첩 손재주 행운 개인특기이름 개인특기수치`: 스탯과 특기를 입력해 새 캐릭터를 1000P로 등록
- `/캐릭터 선택`: 드롭다운에서 활성 캐릭터 변경
- `/캐릭터 목록`: 등록한 캐릭터와 포인트 확인
- `/r`: 사칙연산 주사위 및 힘/민첩/손재주/개인특기 판정
- `/상태`: 캐릭터 스탯, 버프·디버프, SD 이미지, 개인 메모
- `/인벤토리`, `/확인`, `/송금`, `/구매`, `/판매`, `/운영`
- `/돛거`: 대상 동의 후 손재주 대 민첩 판정
- `/낚시`: 미끼 1개를 사용하는 5x5 타이밍 낚시
- `/가위바위보`, `/결투`

## 처음 설정

1. `.env`의 빈 값을 채웁니다.
2. 새 Google Sheet를 서비스 계정 이메일에 편집자로 공유합니다.
3. `npm run setup-sheet`로 필요한 탭과 열을 추가합니다.
4. `npm run deploy`로 Discord 명령어를 등록합니다.
5. `npm start`로 봇을 실행합니다.

`setup-sheet`는 기본적으로 기존 행을 지우지 않습니다. `--reset`은 실제 데이터를 비우므로 사용하지 마세요.

## 시트 입력값

`Users`는 디스코드 계정과 현재 선택한 캐릭터를 연결합니다. 포인트와 인벤토리는 계정이 아니라 캐릭터별로 관리됩니다.

`Characters`의 `strength`, `agility`, `dexterity`, `luck`에는 등록 시 입력한 1~5가 저장됩니다. 보정값은 각각 -10, 0, +10, +20, +25입니다. 개인특기의 상세 설명·보정값과 SD 이미지 URL은 운영진이 시트에서 설정할 수 있습니다.

`StatItemEffects`의 `stat`에는 `strength`, `agility`, `dexterity`, `all` 중 하나를 입력합니다. `duration_minutes`는 지속시간(분), `stackable`은 중첩 가능 여부입니다.

`FishingRewards`의 `rarity`에는 `YELLOW`, `GREEN`, `RED`를 입력합니다. 각 색상마다 보상을 하나 이상 등록해야 하며, `weight`가 클수록 자주 등장합니다. `Items`에는 이름이 정확히 `미끼`인 아이템이 필요합니다.
